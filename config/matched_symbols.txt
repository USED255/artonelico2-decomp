# 已 C 化函数清单（路线 B hybrid 构建的**唯一开关**）
#
# 语义：
#   * 出现在本清单里的符号，其 .text 由 src/matched/<source>.c 经 ee-gcc 3.2-ee-040921
#     编译出的 .o 提供；对应的 asm/cod/<symbol>.s 不再参与汇编与链接。
#   * 不在清单里的符号，照旧走 splat 拆出的 asm/cod/<symbol>.s。
#   * 新增一个已 C 化函数 = 写好 src/matched/<symbol>.c + 在下面加一行。
#
# 格式（每行一项，'#' 起注释，行内注释也生效）：
#   <symbol> [<source-basename>]
# source-basename 省略时默认 = symbol，对应 src/matched/<source-basename>.c。
#
# 编译参数固定为：ee-gcc -O2 -falign-functions=4 -ffunction-sections
#   -O2                 与 M2 探针一致（objdiff 100% 就是在该参数下取得的）
#   -falign-functions=4 把函数起始对齐从默认 8 字节压到 4 字节：原版有大量函数
#                       位于 4 mod 8 的地址上，默认 8 字节对齐会让 ld 插入 4 字节填充、
#                       其后全部地址漂移。
#   -ffunction-sections 每个函数一个 .text.<symbol> 段，链接脚本可以**逐函数**按原位放置。
#
# 编译标志：默认 `-O2 -falign-functions=4 -ffunction-sections`；
#   个别源走别的档位时写进 config/source_flags.tsv（<source-basename>\t<extra-cflags>），
#   build_hybrid.sh 把它**追加在默认标志之后**（gcc 取最后一个 -O）。
#

#   现查明它是 **-O1 档**的空壳包装，`-O1` 下 objdiff 100%（见 source_flags.tsv、OPEN-ISSUES O-05）；
#   改回 -O2 编译会让载荷短 176 B、sha1 变红（负面对照已实测）。
