# 发表政策

[English](PUBLICATION-POLICY.md) | [简体中文](PUBLICATION-POLICY.zh-CN.md)

本仓库是公开仓库。私有导出器按下面的规则生成内容，CI 再校验结果。规则分两部分：**我们发布什么**、**我们绝不发布什么**。

## 1. 我们发布的内容

- `src/matched/` 下的**逆向 C 源码**。
- 配置数据、符号名、地址、函数边界。
- `tools/` 下**我们自己写**的脚本。
- `progress/` 下的进度报告与基线。
- 本仓库里**我们自己写**的文档。

## 2. 我们绝不发布的内容

- 游戏 ROM、游戏镜像、零售可执行文件。
- 游戏资产，或大段游戏文本。
- `splat` 的反汇编树，或**逐条照抄**的汇编清单。
- 反编译器的**全量伪 C 输出**。
- Sony 的编译器、SDK 文件，或属于 Sony 的工具。
- 没有许可证的**第三方材料**。
- 密钥、令牌，以及规避类工具。

关于游戏的事实，只在**我们亲自实测**时才发布。例如函数大小、符号地址、匹配结果。

## 3. 报告问题

如果你发现本仓库含有违反第 2 节的材料，请**开 issue**。
我们把这类报告当**阻塞项**：先移除材料，再做其它工作。

## 4. 说明

- 本政策只约束这个**公开仓库**。
- 私有工作仓库不公开，**不设**入库限制。
- 你必须自备正版游戏。本仓库不提供任何游戏数据。
